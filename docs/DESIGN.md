# Claude 风格皮肤产品设计

## 要解决的问题

部分用户偏好 claude.ai 的暖米白纸面、深炭黑文字、陶土橙强调色与衬线展示标题的阅读体验，
但又不希望修改 DSH 桌面端或 Web 端的安装包文件、破坏原有布局与快捷键，或在升级 DSH 时丢失兼容。
本插件以纯皮肤层提供可随时开关、停用即完全复原的视觉风格。

## 目标体验与边界

- **视觉定位**：浅色采用暖米白画布与浅暖灰表面、深色采用深炭黑画布与温润灰层，
  两套主题均以高对比陶土色作为主按钮与强调色（与开启态开关、发送按钮对比清晰）；展示标题采用衬线风格、
  界面正文采用几何无衬线、代码保持等宽字体，并适当收紧圆角与输入卡片阴影。
  插件图标在透明底上用陶土橙绘制鲸鱼并保留标志性蓝色眼睛。
- **明暗同步与快捷开关**：皮肤跟随 DSH 的 Light / Dark / System 主题自动切换，
  同时在 **设置 → 通用** 提供「Claude 风格」开关，允许用户在不禁用整个插件的情况下临时关闭或恢复皮肤视觉层。
- **非破坏边界**：不替换侧边栏、对话流、输入框、菜单或弹窗等宿主结构与交互逻辑，不改变快捷键、
  焦点环或可访问性语义；如果用户已经在设置中显式指定了字体，尊重用户选择而不强行覆盖；
  不打包专有商用字体，仅优先使用本机已安装字体并用开源近似字体兜底；停用或卸载插件后，所有主题 token、
  字体与表面样式恢复 DSH 原貌，不留残留。

## 成功标准

| 场景 | 可观察结果 |
| --- | --- |
| 浅色与深色主题配色 | 浅色下呈现暖米白主背景、浅暖灰侧栏、白色输入卡与陶土橙发送按钮；深色下切换为炭黑表面与高对比陶土橙强调。 |
| 字体与元素克制修饰 | 欢迎页标题呈现衬线展示字体，正文与代码块各自可读；若用户在设置中自定义字体，自定义字体保持生效。 |
| 明暗与通用开关切换 | 切换 DSH 的 Light / Dark / System 或切换「设置 → 通用 → Claude 风格」开关时，外观立即无残影切换。 |
| 交互与停用复原 | 菜单、弹窗、工具卡、终端、快捷键与焦点环行为与未安装时一致；停用或卸载插件后界面完全恢复 DSH 默认风格。 |
| 插件列表元数据 | 插件管理页展示正确的双语标题、描述、陶土橙鲸鱼图标与详情说明。 |

实现细节、色值映射与样式规则从[项目文档索引](README.md)查阅。
